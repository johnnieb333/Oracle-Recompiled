Oracle Portable v0.2.0-beta — validation scope

Reported Windows gameplay tests: both games launch through the launcher;
owned-item dropdowns, assignments and feature/indicator settings persist.
Seasons: 15 selectable extra items exercised, upgrades and zero-ammo checks.
Ages: 15 selectable extra items exercised, sword/shield holds through scrolls,
simultaneous items, A/B aliases, carry/throw, ammo and zero-ammo checks,
Switch/Long Hook swapping, Cane block creation/removal and all Harp tunes.
Editors reopen after all four Seasons changes and all three Ages travel methods.
Exact speed entry and keyboard Enter capture were tested in gameplay.

Local automated checks: actual interpreter input/initialization fixtures,
Seasons regression checks, owned/sorted menu checks, option persistence,
warp-guard regression checks and full changed C++ translation-unit syntax.
Ages fixture slot-priority selection is simulated; it is not a full game run.

Not fully verified: complete playthroughs, every dungeon/boss or item combination,
companion summoning, Seasons magnetic attraction/repulsion puzzle behavior,
and Ages heavy-statue lifting. These features are not claimed fully tested.
No achievements system or widescreen feature is added by this release.
A fresh-folder release-candidate smoke test is still required.
